About This Project

The Smart Course Recommendation System is a content-based recommender built with Django and Scikit-learn. It analyzes your skills, interests, career goal, and experience level, then uses TF-IDF vectorization and cosine similarity to match you against a catalog of courses — recommending the ones most relevant to you.

Tech Stack
  • Backend: Python, Django
  • Machine Learning: Pandas, NumPy, Scikit-learn (TF-IDF + Cosine Similarity)
  • Frontend: HTML, CSS, Bootstrap, JavaScript
  • Database: SQLite
